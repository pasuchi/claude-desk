Chats

    Agentes

    Un agente combina un modelo, instrucciones (system prompt), servidores MCP y skills.

    Servidores MCP

    Añade servidores locales (comando, p. ej. npx -y @modelcontextprotocol/server-filesystem ~/Documents) o remotos (URL). Si un servidor remoto pide iniciar sesión, se abre tu navegador (funciona con SSO/SAML de tu empresa). Después actívalos en un agente.

    Skills

    Cada skill es una carpeta con un SKILL.md (nombre, descripción e instrucciones). Claude la carga cuando la necesita. Actívalas por agente.

    Token de autenticación

    Pega tu token. Se valida contra la API de Anthropic y se guarda cifrado en el Llavero de macOS. No se usa ningún login con usuario y contraseña.

    ¿Dónde consigo el token?
    Entra en console.anthropic.com → API Keys, crea una clave y pégala aquí. Se aceptan API keys (sk-ant-api…) y otros tokens de acceso de Anthropic; la app los envía en la cabecera Authorization.
